# dotfiles

Mi configuración de Arch Linux — Hyprland, Waybar, Fish, Kitty y más.

![screenshot](assets/screenshot.png)

## Instalación

```bash
git clone https://github.com/JAVIKRD/dotfiles.git
cd dotfiles
bash install.sh
```

El script revisa dependencias, avisa qué falta, y copia las configuraciones a `~/.config` (haciendo backup de lo que ya tengas).

## Incluye

- Hyprland
- Waybar
- Kitty
- Fish shell
- Tmux
- Wofi
- Dunst
- Rofi
- Starship prompt
